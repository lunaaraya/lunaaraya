# Luna Araya Hub v1

Static fashion/lifestyle website designed for GitHub Pages.

## Before publishing
1. Replace placeholder images with Luna's approved images.
2. Replace each `#` Shopee button URL in `index.html` with the real Shopee Affiliate URL.
3. Add Adsterra code only after the Adsterra placement/code is available.
4. Keep the AI/virtual creator disclosure visible.
5. Do not use misleading claims or deceptive links.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a repository. Enable:
Settings → Pages → Deploy from branch → main → /root.

The site does not require a backend or paid hosting.
